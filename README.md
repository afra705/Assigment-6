# 🏋️ FitLog — Workout Library

A modern and responsive workout library web application built with Next.js and TypeScript. Explore different exercises, view detailed workout information, save your favorite workouts, and create a personalized workout plan.

🔗 **Live Demo:** [FitLog Workout Library](https://assigment-6-eta.vercel.app/)

## 🚀 Technologies Used

- **Next.js** — React framework for building web applications
- **React** — Component-based user interface
- **TypeScript** — Type-safe JavaScript development
- **Tailwind CSS** — Utility-first styling
- **DaisyUI** — Prebuilt UI components
- **React Icons** — Icons for the user interface
- **React Toastify** — Toast notifications

## ✨ Key Features

### 1. 🏋️ Workout Library
Browse and explore different workouts with information such as duration, muscle groups, difficulty level, equipment, and calories burned.

### 2. 📋 Workout Details
View detailed information about each exercise, including its description and instructions.

### 3. ❤️ Save Favorite Workouts
Save your favorite exercises for convenient access later.

### 4. 🎯 Personalized Workout Plan
Add workouts to your personal plan and organize exercises for your workout routine.

### 5. 📱 Responsive Design
Enjoy a responsive user interface across mobile phones, tablets, and desktop devices.

### 6. 🔔 Toast Notifications
Receive helpful feedback through toast notifications when interacting with the application.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/afra705/Assigment-6.git
```

### 2. Navigate to the Project Directory

```bash
cd Assigment-6
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

If the project uses environment variables, create a `.env.local` file in the root directory and configure the required values.

For example, if your project fetches data using `NEXT_PUBLIC_SERVER_BASE_URL`, configure it according to your setup:

```env
NEXT_PUBLIC_SERVER_BASE_URL=YOUR_API_BASE_URL
```

Replace `YOUR_API_BASE_URL` with the actual API base URL required by your code. Do not use the localhost URL in production unless your application is running locally.

If the project does not require environment variables, you can skip this step.

### 5. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 6. Build for Production

```bash
npm run build
```

To start the production build locally:

```bash
npm run start
```
