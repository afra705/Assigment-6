🏋️ Workout Library

A modern and responsive workout library web application where users can explore different exercises, view workout details, save their favorite workouts, and create a personalized workout plan.

🚀 Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* DaisyUI
* React Icons
* React Toastify

✨ Key Features

1. Workout Library-
Browse and explore workout library with useful information like duration,muscle group,difficulty etc.

2. Workout Details-
Click on any workout card to view complete details about the selected exercise.

3. Save Workouts-
Users can save their favorite workouts for quick access later.

4. Personalized Workout Plan-
Add workouts to your plan and keep track of the exercises included in your daily routine.

5. Responsive Design-
The website is fully responsive and works smoothly on mobile, tablet, and desktop devices.
